What this tests

The selected fact stays the headline in all four places. Labels and units identify it; clocks calculate from anchors. A deliberate selection above can change the main fact without changing the provider's record.

When the source is unavailable

Only an explicitly selected public clock can remain, marked as last reported. Observed values, status and progress are omitted. Denial, withdrawal, expiry or a terminal source state clears the summary.
